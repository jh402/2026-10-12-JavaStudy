# 데이터 입출력
IO: 프로그램에서 데이터를 읽기/쓰기 기능

Input: 외부 데이터를 프로그램으로 가져오기

Output: 프로그램 데이터를 외부로 보내기

Stream: 단방향으로 데이터가 흐르는 것

## 입출력 스트림
- 단방향으로 입력/출력 데이터가 흐르는 것
- 입출력과 관련된 라이브러리는 java.io 패키지에서 제공
- java.io는 CheckedException이기 때문에 예외처리를 할 것

|구분|바이트 스트림|문자 스트림|
|---|---|---|
|크기|1byte|2byte|
|설명|모든 종류의 데이터를 입출력할 때 사용|문자만 입출력할 때 사용|
|사용처|그림, 멀티미디어, 문자 등|문자만|

**클래스**

최상위 클래스는 모두 추상 클래스

|구분|바이트 입력 스트림|바이트 출력 스트림|문자 입력 스트림|문자 출력 스트림|
|---|---|---|---|---|
|최상위 클래스|InputStream|OutputStream|Reader|Writer|
|하위 클래스|FileOutputStream<br>PrintStream<br>BufferedOutputStream<br>DataOutputStream|FileInputStream<br>BufferedInputStream<br>DataInputStream|FileReader<br>BufferedReader<br>InputStreamReader|FileWriter<br>BufferedWriter<br>PrintWriter<br>OutputStreamWriter|

## OutputStream 클래스
모든 바이트 출력 스트림은 OutputStream 클래스를 상속 받았다.

**주요 메소드**
|메소드|설명|
|---|---|
|void write(int b)|1byte를 출력|
|void write(byte[] b)|매개값으로 주어진 배열 b의 모든 바이트를 출력|
|void write(byte[] b, int off, int len)|매개값으로 주어진 배열 b\[off\]부터 len개의 바이트를 출력|
|void flush()|출력 버퍼에 잔류하는 모든 바이트를 출력|
|void close()|출력 스트림을 닫고 사용 메모리 해제|

## InputStream 클래스
모든 바이트 입력 스트림은 InputStream 클래스를 상속 받았다.

**주요 메소드**
|메소드|설명|
|---|---|
|int read()|1byte를 읽은 후 읽은 바이트를 리턴|
|int read(byte[] b)|읽은 바이트를 매개값으로 주어진 배열에 저장 후 읽은 바이트 수를 리턴|
|void close()|입력 스트림을 닫고 사용 메모리 해제|


## Writer 클래스
모든 문자 출력 스트림 클래스는 Writer 클래스를 상속 받았다.

**주요 메소드**
|메소드|설명|
|---|---|
|void write(int c)|매개값으로 주어진 한 문자를 출력|
|void write(char[] cbuf)|매개값으로 주어진 배열의 모든 문자를 출력|
|void write(char[] cbuf, int off, int len)|매개값으로 주어진 배열에서 cbuf\[off\]부터 len개까지의 문자를 출력|
|void write(String str)|매개값으로 주어진 문자열을 출력|
|void write(String str, int off, int len)|매개값으로 주어진 문자열에서 off부터 len개까지의 문자를 출력|
|void flush()|버퍼에 잔류하는 모든 문자를 출력|
|void close()|출력 스트림을 닫고 사용 메모리를 해제|

## Reader 클래스
모든 문자 입력 스트림 클래스는 Reader 클래스를 상속 받았다.

**주요 메소드**
|메소드|설명|
|---|---|
|int read()|1개의 문자를 읽고 리턴|
|int read(char[] cbuf)|읽은 문자들을 매개값으로 주어진 문자 배열에 저장하고 읽은 문자 수를 리턴|
|void close()|입력 스트림을 닫고, 사용 메모리 해제|

## 보조 스트림
다른 스트림과 연결되어 여러 가지 편리한 기능을 제공해주는 스트림

**자주 사용하는 보조 스트림**
|보조 스트림|기능|
|---|---|
|InputStreamReader|바이트 스트림을 문자 스트림으로 변환|
|BufferedInputStream<br>BufferedOutputStream<br>BufferedReader<br>BufferedWriter|입출력 성능 향상|
|DataInputStream<br>DataOutputStream|기본 타입 데이터 입출력|
|PrintStream<br>PrintWriter|줄바꿈 처리 및 형식화된 문자열 출력|
|ObjectInputStream<br>ObjectOutputStream|객체 입출력|

## BufferedInputStream/BufferedOutputStream 클래스
데이터를 한 번에 읽거나 쓸 때 사용한다.
```java
try {
	//파일 경로 설정
	FileInputStream fis=new FileInputStream("읽을 파일 경로");
	FileOutputStream fos=new FileOutputStream("내보낼 파일 경로");
	//아래 클래스로 한번에 읽거나 내보내기
	BufferedInputStream bis=new BufferedInputStream(fis);
	BufferedOutputStream bos=new BufferedOutputStream(fos);

	//1024바이트로 한번에 읽고 쓰기
	byte[] buffer=new byte[1024];
	int i=0;
	while((i=bis.read(buffer, 0, 1024))!=-1) {
		bos.write(buffer, 0, i);
	}
	//닫기
	bis.close();bos.close();
	fis.close();fos.close();
}catch(Exception ex) {
	ex.printStackTrace();
}
```

## File 클래스
파일과 폴더를 관리하는 클래스

**메소드**
|메소드|설명|
|---|---|
|getName()|파일명 가져오기|
|getPath()|경로명과 파일명 가져오기|
|getParent()|경로명 가져오기|
|length()|파일 크기|
|lastModified()|최종 수정일|
|isHidden()|숨겨진 파일이 있는지 없는지|
|canRead()|파일을 읽을 수 있는지 없는지|
|canWrite()|파일을 쓸 수 있는지 없는지|
|isFile()|파일인지 아닌지|
|isDirectory()|폴더인지 아닌지|
|listFile()|지정된 폴더 안에 있는 모든 파일/폴더 정보|
|mkdir()|폴더 생성|
|mkdirs|폴더 안에 폴더 생성|
|createNewFile()|파일 생성|
|delete()|파일 삭제|
|exists()|파일 존재 여부|
