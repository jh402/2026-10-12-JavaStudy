# 데이터 입출력
IO: 프로그램에서 데이터를 읽기/쓰기 기능

Input: 외부 데이터를 프로그램으로 가져오기

Output: 프로그램 데이터를 외부로 보내기

Stream: 단방향으로 데이터가 흐르는 것

## 입출력 스트림
- 단방향으로 입력/출력 데이터가 흐르는 것
- 입출력과 관련된 라이브러리는 java.io 패키지에서 제공
- java.io는 CheckedException이기 때문에 예외처리를 할 것

|구분|바이트 스트림|문자 스트림|
|---|---|---|
|크기|1byte|2byte|
|설명|모든 종류의 데이터를 입출력할 때 사용|문자만 입출력할 때 사용|
|사용처|그림, 멀티미디어, 문자 등|문자만|

**클래스**
|구분|바이트 입력 스트림|바이트 출력 스트림|문자 입력 스트림|문자 출력 스트림|
|---|---|---|---|---|
|최상위 클래스|InputStream|OutputStream|Reader|Writer|
|하위 클래스|FileOutputStream<br>PrintStream<br>BufferedOutputStream<br>DataOutputStream|FileInputStream<br>BufferedInputStream<br>DataInputStream|

## OutputStream 클래스
- 최상위 클래스
- 추상 클래스
- 모든 바이트 출력 스트림은 OutputStream 클래스를 상속 받았다.

**주요 메소드**
|메소드|설명|
|---|---|
|void write(int b)|1byte를 출력|
|void write(byte[] b)|매개값으로 주어진 배열 b의 모든 바이트를 출력|
|void write(byte[] b, int off, int len)|매개값으로 주어진 배열 b\[off\]부터 len개의 바이트를 출력|
|void flush()|출력 버퍼에 잔류하는 모든 바이트를 출력|
|void close()|출력 스트림을 닫고 사용 메모리 해제|

## InputStream 클래스
- 최상위 클래스
- 추상 클래스
- 모든 바이트 입력 스트림은 InputStream 클래스를 상속 받았다.

**주요 메소드**
|메소드|설명|
|int read()|1byte를 읽은 후 읽은 바이트를 리턴|
|int read(byte[] b)|읽은 바이트를 매개값으로 주어진 배열에 저장 후 읽은 바이트 수를 리턴|
|void close()|입력 스트림을 닫고 사용 메모리 해제|


## File 클래스
파일과 폴더를 관리

**메소드**
|메소드|설명|
|---|---|
|getName()|파일명 가져오기|
|getPath()|경로명과 파일명 가져오기|
|getParent()|경로명 가져오기|
|length()|파일 크기|
|lastModified()|최종 수정일|
|isHidden()|숨겨진 파일이 있는지 없는지|
|canRead()|파일을 읽을 수 있는지 없는지|
|canWrite()|파일을 쓸 수 있는지 없는지|
|isFile()|파일인지 아닌지|
|isDirectory()|폴더인지 아닌지|
|listFile()|지정된 폴더 안에 있는 모든 파일/폴더 정보|
|mkdir()|폴더 생성|
|mkdirs|폴더 안에 폴더 생성|
|createNewFile()|파일 생성|
|delete()|파일 삭제|
|exists()|파일 존재 여부|
