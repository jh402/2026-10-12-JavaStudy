### 11.1.1. Object 클래스
- 자바 클래스의 최상위 클래스
- extends 키워드로 다른 클래스를 상속하지 않으면 암시적으로 Object 클래스 상속

|메소드|기능|
|---|---|
|void finalize()|소멸자|
|Object clone()|객체 복제(메모리를 따로 생성-깊은 복사)|
|String toString()|객체를 문자열화(메소드 생략 가능)|
|public boolean equals(Object obj)|객체 주소값 리턴|
|int hashCode()|객체 구분|
|getClass()|객체 얻기|

### 11.1.2. String 클래스
|메소드|기능|
|---|---|
|toUpperCase()|소문자를 대문자로 변환|
|toLowerCase()|대문자를 소문자로 변환|
