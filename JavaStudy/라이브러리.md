# 11. 라이브러리

## 11.1. java.lang

### 11.1.1. Object 클래스

|메소드|기능|
|---|---|
|finalize()|소멸자|
|clone()|객체 복제(메모리를 따로 생성-깊은 복사)|
|toString()|객체를 문자열화(메소드 생략 가능)|
|equals()|객체 주소값 리턴|
|hashCode()|객체 구분|
|getClass()|객체 얻기|

### 11.1.2. String 클래스
|메소드|기능|
|---|---|
|toUpperCase()|소문자를 대문자로 변환|
|toLowerCase()|대문자를 소문자로 변환|
