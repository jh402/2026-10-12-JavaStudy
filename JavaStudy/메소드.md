# 6. 메소드
특정 기능을 수행하는 코드의 묶음
필요할 때마다 호출하여 사용할 수 있는 재사용 가능한 코드 블록

**장점**
- 코드를 모듈화하여 관리하기 쉬움
- 중복 코드를 줄임
- 가독성과 유지보수성 향상

## 6.1. 실행 과정
1. 메소드 호출 : 메소드 이름과 전달된 인자를 통해 실행이 시작
2. 매개변수 전달 : 호출 시 전달한 값이 매개변수에 저장
3. 구현부 실행 : 메소드 내부 코드가 순차적으로 실행
4. 리턴값 반환(리턴형이 있는 경우) : 실행 괄과를 호출한 곳으로 반환
5. 호출한 곳으로 돌아감 : 메소드 실행이 완료, 호출한 위치로 복귀

## 6.2. 메소드 호출 방법
### 6.2.1. 인스턴스 메소드
객체를 생성해야 호출 가능

**호출문**<br>
객체.메소드이름(인자);
```java
Calcaulator cal=new Calculator();
int result=cal.add(10, 20);
```
### 6.2.2. 정적 메소드
클래스 이름으로 호출 가능

**호출문**<br>
클래스이름.메소드이름(인자);
```java
int result=Calculator.multiply(10, 20);
```
정적 메소드는 주로 유틸리티 기능이나, 객체 생성 없이 바로 사용하고 싶을 때 사용

## 6.3. 형식 (기본 구조)
리턴형 메소드이름(매개변수){<br>
&ensp;//구현부<br>
&ensp;return 값;<br>
}<br>

예시
```java
public int add(int a, int b){
  return a+b;
}
```

### 6.3.1. 리턴형
메소드가 호출한 곳으로 반환하는 값의 데이터 타입
|리턴형|설명|
|---|---|
|void|값을 반환하지 않음(반환문 없음)|
|int, double boolean 등|기본형 데이터를 반환|
|String|문자열을 반환|
|객체 타입(클래스명)|객체를 반환|

리턴형이 `void`인 경우, `return` 생략 가능

**return문**
메소드의 실행을 강제 종료하고 호출한 곳으로 돌아간다는 의미<br>
메소드 선언에 리턴 타입이 있을 경우 return문 뒤에 리턴값을 추가로 지정
```java
return 값;
```

return문 이후에 실행문을 작성하면 'Unreachable code'라는 컴파일 에러 발생
```java
int plus(int x, int y){
  int result=x+y;
  return result;
  System.out.println(result);//Unreachable code
}
```
return문 이후의 실행문은 결코 실행되지 않기 때문이다.

### 6.3.2. 매개변수
메소드에 전달되는 값으로 메소드 내부에서 사용

**특징**
- 데이터 타입과 개수를 정확히 맞춰야 함
- 여러 개의 매개변수를 사용 가능
- 기본형과 참조형 모두 가능

참조형(객체)의 경우, 객체 자체가 전달되어 메소드 내부에서 값 변경이 가능

### 6.3.3. 구현부(메소드 본문)
실제 동작하는 코드를 작성하는 부분
- 중괄호 안에 작성
- 여러 줄의 로직을 작성 가능
- 리턴형이 있을 경우 반드시 리턴형에 맞는 값을 반환

### 6.3.4. 선언부
메소드의 이름, 매개변수, 리턴형을 정의하는 부분
- 메소드의 이름은 의미있게 작성
- 매개변수의 타입과 개수를 정확히 명시
- 리턴형은 호출한 곳에서 받을 타입을 의미
```java
int calculate(int a, int b){//<-선언부
  //구현부
  return a+b;
}
```
