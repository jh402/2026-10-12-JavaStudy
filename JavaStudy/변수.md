# 2. 변수
하나의 값을 저장할 수 있는 메모리 공간

## 2.1. 데이터 타입
모든 변수에는 타입이 있으며 타입에 따라 저장할 수 있는 값의 종류와 범위가 달라짐
### 2.1.1. 정수 타입
|타입|메모리 크기|
|---|---|
|byte|1 byte|
|char|2 byte|
|short|2 byte|
|int|4 byte|
|long|8 byte|
### 2.1.2. 실수 타입
|타입|메모리 크기|
|---|---|
|float|4 byte|
|double|8 byte|
### 2.1.3. 논리 타입
|타입|메모리 크기|
|---|---|
|boolean|1 byte|

## 2.2. 변수 선언
타입 변수이름; 형식으로 선언<br>
```
int age;//변수 선언
age=20;//값 대입
```
초기화 : 변수에 최초로 값을 대입하는 행위

## 2.3. 변수 이름
- 첫 글자는 문자
- 중간부터 문자, 숫자, $, _ 포함 가능

## 2.4. 타입 변환
데이터 타입을 다른 타입으로 변환하는 것<br>
**크기 순서** : byte &#60; short &#60; int &#60; long &#60; float &#60; double<br>
자동(묵시적) 타입 변환 : 작은 크기의 타입이 큰 크기의 타입에 자장될 때 발생<br>
강제(명시적) 타입 변환 : 큰 타입을 작은 타입을 쪼개어 저장하는 것
