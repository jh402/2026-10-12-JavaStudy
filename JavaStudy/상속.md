# 8. 상속
## 8.1. 상속이란
- 부모가 자식에게 물려주는 행위
- 부모 클래스의 필드와 메소드를 자식 클래스에게 물려줌
- 클래스를 재사용하여 중복되는 코드를 줄여줌

## 8.2. 형태
[접근제한자] class 자식클래스 extends 부모클래스
```java
//부모클래스
class Animal{
  String name;
  void sound(){
    System.out.println("동물 소리");
  }
}
//자식클래스
class Dog extends Animal{
  String type;
}
```

## 8.3. 생성자 실행 순서
1. 객체 메모리 할당 및 기본값 초기화
2. 부모 클래스의 필드 초기화식, 초기화 블록 실행
3. 부모 클래스 생성자 실행
4. 자식 클래스의 필드 초기화식, 초기화 블록 실행
5. 자식 클래스 생성자 실행

부모 생성자가 먼저 실행되는 이유 : 부모의 부분이 먼저 초기화 되어야 자식 객체가 정상적으로 생성

### 8.4. super(부모 클래스 참조)
- 부모 클래스의 필드에 접근 시 사용
- 부모 클래스의 메소드에 접근 시 사용

**super()**
- 부모 클래스의 생성자 호출
- 생성자의 첫 번째 문장에 위치
```java
class Animal{
  int age;
  //super()로 생성자 호출
  Animal(){
    this.age=10;
  }
}
class Dog extends Animal{
  Dog(){
    super();//첫 번째 문장에 위치
  }
}
```

## 8.4. 다형성
- 부모 타입의 참조 변수로 자식 객체를 참조
- 실제 객체의 타입에 따라 메소드가 실행

### 8.4.1. 오버라이딩
- 부모의 메소드를 자식이 재정의
- 실제 객체 타입에 따라 실행
- 메소드 시그니처(이름, 매개변수, 반환타입)가 동일해야 함
```java
//부모클래스
class Animal{
  String name;
  void sound(){
    System.out.println("동물 소리");
  }
}
//자식클래스
class Dog extends Animal{
  String type;
  System.out.println("멍멍");
}
```

### 8.4.2. 오버로딩
- 같은 클래스 내에서 같은 이름의 메소드 여러 개
- 매개변수의 개수/타입/순서가 다름
```java
void bark(){...}
void bark(String type){...}
void bark(int count){...}
```

**생성자 오버로딩**
```java
class A{
  int a, b;
  String c;
  A(){...}
  A(int a){...}
  A(String c){...}
  A(int a, int b, int c){...}
}
```
