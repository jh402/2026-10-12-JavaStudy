# 쓰레드
프로그램 안에서 여러 작업을 동시에 실행하는 실행 흐름

## 메인 쓰레드
자바 프로그램은 메인 쓰레드가 `main()` 메소드를 실행하면서 시작

## 쓰레드 생성 방법
1. Thread 상속
```java
class MyThread extends Thread{
  @Override
  public void run(){
    //쓰레드가 실행할 코드
  }
}
```
2. Runnable 구현
```java
class Task implements Runnable{
  @Override
  public void run(){
    //쓰레드가 실행할 코드
  }
}
```
3. 람다식
```java
Thread thread=new Thread(()->{
  //쓰레드가 실행할 코드
});
```
쓰레드는 `start()` 메소드를 호출하면 `run()` 메소드를 실행
```java
thread.start()
```

## 쓰레드 상태
1. 쓰레드 객체를 생성(NEW)
2. start() 메소드 호출 -> 실행 대기 상태(RUNNABLE)
3. CPU 스케쥴링에 따라 CPU 점유 후 run() 메소드 실행(RUNNING)
4. 실행 중 대기 상태로 돌아가거나 일시 정지 상태(쓰레드가 실행할 수 없는 상태)로 가기도 한다.
5. run() 메소드가 종료되면 쓰레드의 실행은 멈추게 된다. 이를 종료 상태(TERMINATED)라고 한다.
