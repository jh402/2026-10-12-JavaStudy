# 쓰레드
프로그램 안에서 여러 작업을 동시에 실행하는 실행 흐름

## 메인 쓰레드
자바 프로그램은 메인 쓰레드가 `main()` 메소드를 실행하면서 시작

## 쓰레드 생성 방법
1. Thread 상속
```java
class MyThread extends Thread{
  @Override
  public void run(){
    //쓰레드가 실행할 코드
  }
}
```
2. Runnable 구현
```java
class Task implements Runnable{
  @Override
  public void run(){
    //쓰레드가 실행할 코드
  }
}
```
3. 람다식
```java
Thread thread=new Thread(()->{
  //쓰레드가 실행할 코드
});
```
쓰레드는 `start()` 메소드를 호출하면 `run()` 메소드를 실행
```java
thread.start()
```

## 쓰레드 상태
1. 쓰레드 객체를 생성(NEW)
2. start() 메소드 호출 -> 실행 대기 상태(RUNNABLE)
3. CPU 스케쥴링에 따라 CPU 점유 후 run() 메소드 실행(RUNNING)
4. 실행 중 대기 상태로 돌아가거나 일시 정지 상태(쓰레드가 실행할 수 없는 상태)로 가기도 한다.
5. run() 메소드가 종료되면 쓰레드의 실행은 멈추게 된다. 이를 종료 상태(TERMINATED)라고 한다.

## 동기화
여러 쓰레드의 동시 접근을 제어

### 동기화 메소드
실행 즉시 객체는 잠금이 일어나고 메소드 실행이 끝나면 잠금이 풀린다.
```java
public synchronized void method(){}
```

### 동기화 블록
일부 영역에 객체 잠금을 걸고 싶을 때 사용한다. 
```java
public void method(){
  //쓰레드가 실행할 수 있는 영역
  synchronized(공유객체){
    //단 하나의 쓰레드만 실행할 수 있는 영역
  }
  //쓰레드가 실행할 수 있는 영역
}
```

## ThreadPool
쓰레드를 미리 만들어 두고 필요할 때 재사용 하는 방식

### ThreadPool 생성
- 고정 개수 쓰레드
```java
ExecutorService executorService=Executors.newFixedThreadPool(쓰레드 갯수);
```
- 하나의 쓰레드
```java
ExecutorService executorService=Executors.newSingleThreadExcutor();
```
- 필요 시 생성
```java
ExecutorService executorService=Executors.newCachedThreadPool();
```
- 예약, 주기 실행
```
ExecutorService executorService=Executors.newScheduledThreadPool(쓰레드 갯수);
```

### ThreadPool 종료
ThreadPool의 쓰레드는 main 쓰레드가 종료되더라도 작업을 처리하기 위해 계속 실행 상태로 남아있기 때문에 아래 두 메소드 중 하나를 실행해야 한다.

|메소드|설명|
|---|---|
|void shutdown()|현재 처리 중인 작업 뿐만 아니라 작업 큐에 대기하고 있는 모든 작업을 처리한 뒤에 쓰레드풀을 종료|
|List<Runnable> shutdownNow()|현재 작업 처리 중인 쓰레드를 interrupt해서 작업을 중지시키고 쓰레드풀을 종료<br>리턴값을 작업 큐에 있는 미처리된 작업의 목록|
