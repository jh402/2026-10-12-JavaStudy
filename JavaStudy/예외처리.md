# 10. 예외처리
프로그램 실행 중 발생하는 문제를 감지하고 적절하게 처리하여 프로그램이 갑자기 종료되지 않도록 하는 기능
## 10.1. 목적
- 프로그램의 비정상 종료 방지
- 오류 상황을 사용자에게 안내
- 오류 원인 파악 및 디버깅 도움
- 정상적인 프로그램 흐름 유지
- 자원(파일, DB 등) 관리

## 10.2. try-catch
### 10.2.1. 기본 문법
```java
try{
  //예외가 발생할 수 있는 코드
  //예외가 발생하면 catch로 이동
}catch(Exception e){
  //예외가 발생했을 때 처리
}finally{
  //마지막 정리 작업
}
```
