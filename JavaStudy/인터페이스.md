# 9. 인터페이스
클래스가 구현해야 하는 기능의 규격(설계도)
## 9.1. 기본 문법
- `interface`로 인터페이스 선언
- 인터페이스에서 클래스로 상속할 때 `implements` 사용
```java
interface InterfaceA{
  void methodA();
}
class ClassA implements InterfaceA{
  @Override
  public void methodA(){...}
}
```

- 인터페이스에서 인터페이스로 상속할 때 `extends` 사용
```java
interface InterfaceA{
  void methodA();
}
interface InterfaceB extends InterfaceA{
  void methodB();
}
```
- 다중 상속 가능
```java
interface InterfaceA{
  void methodA();
}
interface InterfaceB{
  void methodB();
}
class ClassA implements InterfaceA, InterfaceB{
  void methodA(){...}
  void methodB(){...}
}
```

## 9.2. 주요 특징
- 객체 생성 불가
- 생성자 없음
- 필드에는 상수만 가능(public static final)
- 추상 메소드 구현 필수
- 다중 상속 가능
