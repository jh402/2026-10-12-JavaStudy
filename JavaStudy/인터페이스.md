# 9. 인터페이스
클래스가 구현해야 하는 기능의 규격(설계도)

## 9.1. 주요 특징
- 객체 생성 불가
- 생성자 없음
- 필드에는 상수만 가능(public static final)
- 추상 메소드 구현 필수
- 다중 상속 가능
- 다형성의 핵심
- 실무에서 확장성과 유지보수에 필수

## 9.2. 기본 문법
- `interface`로 인터페이스 선언
- 인터페이스에서 클래스로 상속할 때 `implements` 사용
```java
interface InterfaceA{
  void methodA();
}
class ClassA implements InterfaceA{
  @Override
  public void methodA(){...}
}
```

- 인터페이스에서 인터페이스로 상속할 때 `extends` 사용
```java
interface InterfaceA{
  void methodA();
}
interface InterfaceB extends InterfaceA{
  void methodB();
}
```
- 다중 상속 가능
```java
interface InterfaceA{
  void methodA();
}
interface InterfaceB{
  void methodB();
}
class ClassA implements InterfaceA, InterfaceB{
  void methodA(){...}
  void methodB(){...}
}
```

## 9.3. 인터페이스 메소드 종류
- 추상 메소드 : 구현 클래스에서 반두스 구현
- default 메소드 : 기본 구현 제공 (Java 8+)
- static 메소드 : 인터페이스 이름으로 호출 (Java 8+)
- private 메소드 : 인터페이스 내부 공통 기능 (Java 9+)

## 9.4. 추상 클래스와 인터페이스 비교
|구분|추상 클래스|인터페이스|
|---|---|---|
|목적|공통 기능 공유|기능 규격 정의|
|필드|일반 필드 가능|상수만 가능|
|메소드|구현된 메소드<br>미구현된 메소드|미구현된 메소드<br>JDK1.8부터 default메소드 구현 가능|
|생성자|있음|없음|
|접근지정어|모두 사용 가능|only public|
|다중 구현|불가능|가능|

## 9.5. 주의점
- 추상 메소드는 모두 구현
- 구현하는 메소드는 모두 `public`
- default 메소드 충돌 시 명시적으로 해결
