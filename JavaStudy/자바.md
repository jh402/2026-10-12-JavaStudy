## Java
### 자바의 특징
- **이식성이 높은 언어**<br>
  \- 자바로 개발된 프로그램은 소스파일을 수정하지 않아도 JRE가 설치되어 있다면 모든 운영체제에서 실행 가능
- **객체지향 언어**<br>
  \- 캡슐화, 상속, 다형성 기능을 지원
- **함수적 스타일 코딩을 지원**<br>
  \- 람다식을 자바 8부터 지원
- **메모리를 자동으로 관리**<br>
  \- 쓰레기 수집기(Garbage Collector)가 사용하지 않는 객체를 제거
- **다양한 애플리케이션을 개발**<br>
  \- 다양한 운영체제에서 실행되는 프로그램을 개발이 가능
- **멀티 스레드를 쉽게 구현**<br>
  \- 멀티 스레드 관련 라이브러리 API를 제공
- **동적 로딩을 지원**<br>
  \- 실행 시 모든 객체가 생성되지 않고 필요한 시점에 클래스를 동적 로딩하여 객체를 생성
- **오픈소스 라이브버리가 풍부**<br>
  \- 자바는 오픈소스 언어이기 때문에 자바에서 사용하는 라이브러리 또한 오픈소스가 넘쳐남

### 바이트코드 파일
1. 자바 소스 파일의 확장명은 .java
2. 자바 소스파일을 javac 명령어로 컴파일
3. 컴파일 결과는 확장명이 .class인 바이트코드 파일로 생성

### 자바 가상 머신(JVM)
자바 가상 머신(JVM)은 운영체제에서 이해하는 기계어로 번역해야 하므로 운영체제별로 다르게 설치

1. java명령어 사용
2. JVM이 바이트코드를 해석
3. 기계어로 변역 후 실행
