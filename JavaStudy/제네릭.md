# 12. 제네릭
- 하나의 클래스가 여러 자료형을 처리하는 방법
- 잘못된 자료형을 컴파일 단계에서 방지
- 형변환 없이 안전하게 사용

## 12.1. 와일드카드
|와일드카드|설명|
|---|---|
|<?>|모든 타입 가능(읽기 전용)|
|<? extends T>|T와 자식 타입(데이터 읽기)|
|<? super T>|T와 부모 타입(데이터 추가)|

**PECS 원칙**
- 목적에 따라 `extends` 또는 'super` 사용
- `extends`: 데이터를 읽을 때
- `super`: 데이터를 추가할 때

## 12.1. 문법
- 보통 타입 파라미터는 '<>' 안에 T, E, K, V 사용
- 타입 파라미터에 타입을 지정하지 않으면 Object타입이 암묵적으로 사용

```java
class className<T>{
  T data;
  public T void print(T data){
    System.out.println(data);
  }
}
```
- 여러 타입 사용도 가능
```java
class className<K, V>{
  private K key;
  private V value;
}
```
