# 12. 제네릭
- 하나의 클래스가 여러 자료형을 처리하는 방법
- 잘못된 자료형을 컴파일 단계에서 방지
- 형변환 없이 안전하게 사용

## 12.1. 문법
- 보통 <>안에 T, E, K, V 사용
```java
class className<T>{
  T data;
  public T void print(T data){
    System.out.println(data);
  }
}
```
- 여러 타입 사용도 가능
```java
class className<K, V>{
  private K key;
  private V value;
}
```
