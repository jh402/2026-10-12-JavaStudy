# 4. 제어문
## 4.1. 제어문이란?
-프로그램의 실행 순서를 제어하는 문법<br>
-조건에 따라 다른 동작을 수행하거나, 반복적으로 실행할 때 사용

## 4.2. 종류
1. 조건문 / 선택문 : 조건에 따라 실행할 코드를 결정
2. 반복문 : 같은 코드를 여러 번 실행
3. 분기문 : 반복을 제어하거나 실행을 중단
***
## 4.3. 조건문
조건식의 결과에 따라 실행할 코드를 선택
<br><br>
**조건식에 사용할 수 있는 연산자**
- 비교연산자 : ==, !=, &lt;, &gt;, &lt;=, &gt;=<br>
- 논리연산자 : &&, ||, !<br>
- 부정연산자 : !


### 4.2.1. 단일조건문(if)
특정 조건이 참인지 거짓인지에 따라 코드를 실행
```
if(조건식){
  //조건이 true일 때 실행
}
```

### 4.2.2. 선택조건문(if~else)
true와 false를 나눠서 작업
```
if(조건식){
  //조건이 true일 때 실행
}
else{
  //조건이 false일 때 실행
}
```

### 4.2.3. 다중조건문(if\~else if\~else)
여러 조건 중 하나를 선택하여 실행
```
if(조건식1){
  //조건식1이 true일 때 실행
}
else if(조건식2){
  //조건식2가 true일 때 실행
}
else{
  //조건식1, 조건식2가 false일 때 실행
}
```

## 4.2. 선택문 (switch)
하나의 변수 값에 따라 여러 경우를 처리

```
switch (변수){
  case 값1:
    실행문;//변수가 값1일 때 실행
    break;
  case 값2:
    실행문;//변수가 값2일 때 실행
    break;
  default:
    실행문;//변수값과 동일한 case가 없다면 실행
}
```
default는 생략 가능

**주의**<br>
break를 생략하면 다음 case까지 실행

**JDK 14 이후에 추가된 switch문**
```
switch(변수){
  case 값1->실행문;
  case 값2, 값3, 값4->실행문;
  case 값5->실행문;
  default->실행문;
}
```
자동으로 break를 포함

## 4.3. 반복문
조건이 만족되는 동안 같은 코드를 반복 실행

### 4.3.1. for문
반복횟수가 정해져 있을 때 사용

```
for(초기화식; 조건식; 증감식){
  실행문;
}
```
**실행 순서**:초기화식 → 조건식 → 실행문 → 증감식 → 조건식부터 반복


### 4.3.2. while문
조건을 먼저 검사할 때 사용

```
while(조건식){
  실행문;
}
```
**실행 순서** : 조건식 → 실행문 → 반복

### 4.3.3. do~while문
최소 한 번은 실행해야 할 때 사용

```
do{
  실행문;
}while(조건식)
```
**실행 순서** : 실행문 → 조건식 → 반복
***
## 4.4. 반복 제어문
반복문을 중단하거나, 특정 부분을 제외할 때 사용

### 4.4.1. break
반복문을 완전히 종료
```
for(int i=1;i<=5;i++){
  if(i==3)
    break;
  System.out.println(i+" ");
}
```
실행결과<br>
1 2

### 4.4.2. label이 있는 break
이름표(label)를 지정하고, 해당 이름표가 붙은 반복문 전체를 빠져나옴<br>
여러 반복문 중 바깥쪽까지 종료해야 할 때 사용

```
Outer:
for(int i-1;i<=3;i++){
  for(int j=1;j<=3;j++){
    System.out.println(i+". "+j);
    if(i==2&&j==2)
      break Outer;//바깥쪽 반복문 종료
  }
}
```
실행 결과<br>
1\. 1<br>
1\. 2<br>
1\. 3<br>
2\. 1<br>
2\. 2<br>

### 4.4.3. continue
현재 반복의 남은 코드를 건너뛰고 다음 반복으로 넘어감

```
for(int i=1;i<=5;i++){
  if(i==3)
    continue;
  System.out.println(i+" ");
}
```
실행결과<br>
1 2 4 5
