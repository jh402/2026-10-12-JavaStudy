## 제어문
### 제어문이란?
-프로그램의 실행 순서를 제어하는 문법<br>
-조건에 따라 다른 동작을 수행하거나, 반복적으로 실행할 때 사용

### 종류
1. 조건문 / 선택문 : 조건에 따라 실행할 코드를 결정
2. 반복문 : 같은 코드를 여러 번 실행
3. 분기문 : 반복을 제어하거나 실행을 중단

### 조건문
조건식의 결과에 따라 실행할 코드를 선택
<br><br>
**조건식에 사용할 수 있는 연산자**
- 비교연산자 : ==, !=, &lt;, &gt;, &lt;=, &gt;=<br>
- 논리연산자 : &&, ||, !<br>
- 부정연산자 : !


**단일조건문(if)**<br>
특정 조건이 참인지 거짓인지에 따라 코드를 실행
```
if(조건식){
  //조건이 true일 때 실행
}
```

**선택조건문(if~else)**<br>
true와 false를 나눠서 작업
```
if(조건식){
  //조건이 true일 때 실행
}
else{
  //조건이 false일 때 실행
}
```

**다중조건문(if\~else if\~else)**<br>
여러 조건 중 하나를 선택하여 실행
```
if(조건식1){
  //조건식1이 true일 때 실행
}
else if(조건식2){
  //조건식2가 true일 때 실행
}
else{
  //조건식1, 조건식2가 false일 때 실행
}
```

### 선택문 (switch)
하나의 변수 값에 따라 여러 경우를 처리

예시
```
switch (menu){
  case 1:
    System.out.println("조회");
    break;
  case 2:
    System.out.println("등록");
    break;
  default:
    System.out.println("잘못된 메뉴");
}
```

**주의**<br>
break를 생략하면 다음 case까지 실행

**JDK 14 이후에 추가된 switch문**
```
switch(no){
  case 1->//실행문장
  case 2, 3, 4->//실행문장
  case 5->//실행문장
  default->//실행문장
}
```
자동으로 break를 포함
