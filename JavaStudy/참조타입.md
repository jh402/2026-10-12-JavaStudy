## 참조타입
객체의 번지를 참조하는 타입<br>
배열, 열거, 클래스, 인터페이스 타입이 있음

### 메모리 사용 영역
- **메소드 영역**<br>
바이트코드 파일을 읽은 내용이 저장되는 영역<br>
상수, 정적 필드, 메소드 코드, 생성자 코드 등이 저장

- **힙 영역**<br>
객체가 생성되는 영역<br>
객체의 번지는 메소드 영역과 스택 영역의 상수와 변수에서 참조 가능

- **스택 영역**<br>
메소드를 호출할 때마다 생성되는 프레임이 저장되는 영역<br>
호출이 끝나면 프레임은 자동 제거<br>
프레임 내부의 로컬 변수 스택에서 기본 타입 변수와 참조 타입 변수가 생성되고 제거됨

### null
참조 타입 변수는 아직 번지를 저장하고 있지 않다는 뜻으로 null값을 가질 수 있음
null로 초기화된 참조 변수는 스택 영역에 생성됨

**NullPointerException**
변수가 null인 상태에서 객체의 데이터나 메소드를 사용하려 할 때 발생하는 예외

### String 클래스
#### String 클래스란?
String 클래스는 문자들의 집합(문자열)을 표현하는 클래스<br>
문자열은 ""(큰따옴표)로 감싸서 사용<br>

#### String의 주요 특징
문자열 리터럴은 문자열 풀에 저장<br>
다양한 메소드를 제공하여 문자열을 쉽게 다룸<br>
자바에서 문자열 처리는 String 클래스를 사용하는 것이 일반적<br>
String은 한 번 생성하면 내용이 변경되지 않는 불변 객체<br>

**불변 객체**<br>
값을 변경할 수 없고 변경이 필요하면 새로운 객체를 생성

#### String 생성 방법
|방법|예시|설명|
|---|---|---|
|문자열 리터럴|String s="Hello";|문자열 풀에 저장(권장)|
|new 키워드|String s=new String("Hello");|새로운 객체 생성(비효율적)|
|문자열 배열|char[] arr={'H', 'e', 'o', 'l', 'l'};|문자 배열로 생성|
|바이트 배열|byte[] arr=(...);<br>String s= new String(arr);|바이트 배열로 생성(인코딩 필요)|

#### String의 주요 메소드(일부)
|메소드|설명|예시|결과|
|---|---|---|---|
|**length()**|문자열 길이 변환|"Hello".length()|5|
|**charAt(int)**|특정 위치의 문자 변환|"Hello".charAt(1)|'e'|
|**indexOf(String)**|문자열의 위치 찾기|"Hello".indexOf("l")|2|
|**substring(int, int)**|부분 문자열 변환|"Hello".substring(1, 4)|"ell"|
|**equals(Object)**|문자열 동일 여부|"abc".equals("abc")|true|
|**equalsIgnoreCase()**|대소문자 구분없이 비교|"abc".equalsIgnoreCase("ABC")|true|
|compareTo(String)|사전 순서 비교|"abc".compareTo("abd")|-1|
|concat(String)|문자열 연결|"Hello".concat("World")|"HelloWorld"|
|**replace(char, char)**|문자 변경|"Hello".replace('l', 'L')|"HeLLo"|
|**toUpperCase()**|대문자로 변환|"hello".toUpperCase()|"HELLO"|
|**toLowerCase()**|소문자로 변환|"HELLO".toLowerCase()|"hello"|
|trim()|양쪽 공백 제거|" hi ".trim()|"hi"|
|split(String)|문자열 분리(배열 반환)|"a, b, c".split(",")|[a, b, c]|
|contains(String)|포함 여부 확인|"hello".contains("he")|true|
|startsWith(String)|시작 여부 확인|"hello".startsWith("he")|true|
|endsWith(String)|끝 여부 확인|"hello".endsWith("lo")|true|
|isEmpty()|빈 문자열 여부|"".isEmpty()|true|
|isBlank()|공백이 있는지 확인|" ".isBlank()|true|

### 배열
#### 배열이란?
같은 자료형의 데이터를 여러 개 저장할 수 있는 자료구조

배열 객체를 참조하는 참조 변수의 값은 스택(Stack)에 저장<br>
실제 배열 객체와 요소가 저장되는 영역은 힙(Heap) 에 저장

#### 배열을 사용하는 주요 목적
1. 여러 데이터 관리
2. 반복 처리
3. 데이터 검색과 정렬
4. 데이터 전달과 복사
5. 자료구조 학습의 기초

#### 배열 선언, 생성, 초기화
- 선언

아래 코드는 배열 변수만 선언한 상태
```
int[] arr;//권장
int arr[];
```

- 생성

아래 코드는 정수 5개를 저장할 수 있는 배열 객체를 생성
```
int[] number=new int[5];
```
자동으로 기본값으로 초기화 됨
|자료형|기본 초기값|
|---|---|
|int|0|
|long|0L|
|double|0.0|
|boolean|false|
|char|'\u0000'|
|참조형|null|


- 초기화
```
int[] number={10, 20, 30, 40, 50};
```

#### 배열 복사 방법
- 대입 연산자
참조값만 복사
```
int[] a={10, 20, 30}
int[] b=a;
```
- clone()
새로운 배열 생성
```
int[] b=a.clone();
```

- Arrays.copyOf()
크기 지정 복사
```
int[] b=Arrays.copyOf(a, a.length);
```

- System.arraycopy()
특정 구간 복사
```
System.arraycopy(a, 1, b, 0, 3); //a의 1~3번째 요소를 b로
```

- 반복문
직접 복사(필요에 따라 변환 가능)
```
for(int i=0;i<a.length;i++){
  b[i]=a[i];
}
```

#### 얕은 복사, 깊은 복사
- 얕은 복사
배열은 새로 생성되지만 내부 객체는 동일 참조<br>
객체 배열에서 주로 발생<br>
내부 객체 변경 시 원본에도 영향 가능

- 깊은 복사
배열과 내부 객체까지 새로 생성<br>
새로 독립적인 객체가 생성<br>
내부 데이터까지 완전히 분리

#### for-each문

##### for문과 비교
|평가기준|일반 for문|for-each문|
|---|---|---|
|인덱스 제어|O|X|
|역순 순회|O|X|
|원본 데이터 수정|O|X|
|코드 가독성|정밀한 제어에 유리|전체 데이터 단순 순회시 압도적|
단순히 모든 요소를 읽을 때는 for-each문, 인덱스가 필요하거나 원본을 변경해야 할 때는 일반 for문
