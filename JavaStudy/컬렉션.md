# 13. 컬렉션
컬렉션은 배열과 다르게 제한 없이 객체를 저장이 가능

```
           Collection
      ┌─────────┴─────────┐
    List                 Set            Map
      ├─ ArrayList        ├─ HashSet     ├─ HashMap
      ├─ Vector           └─ TreeSet     ├─ Hashtable
      └─ LinkedList                      ├─ TreeMap
                                         └─ Properties
```
- List와 Set은 Collection 인터페이스를 상속 받음
- List, Set, Map은 인터페이스

## 13.1. List, Set, Map 비교
|인터페이스|특징|
|---|---|
|List|순서를 유지하고 저장<br>중복 저장 가능|
|Set|순서를 유지하지 않고 저장<br>중복 저장 X|
|Map|키와 값으로 구성된 엔트리 저장<br>키는 중복 저장 X|

**List 구현 클래스 비교**
|클래스|ArrayList|Vector|LinkedList|
|---|---|---|---|
|순서|있음|있음|있음|
|조회|빠름|빠름|느림|
|동기화|X|O|X|
|추가/삭제|느림|느림|빠름|

**사용처**
- ArrayList: 실무에서 가장 일반적인 기본 목록
- Vector: 성능 저하 문제로 인한 레거시 코드 전용
- LinkedList: 큐 및 양방향 탐색 구현에 유리

**Map 구현 클래스 비교**
|클래스|HashMap|LinkedHashMap|TreeMap|Hashtable|
|---|---|---|---|---|
|정렬|보장 안 함|입력 순서|key 기준 오름차순 정렬|보장 안 함|
|동기화|X|X|X|O|

****
- HashMap: 가장 널리 쓰이는 표준 Map
- LinkedHashMap: 캐시 알고리즘 구현에 유리
- TreeMap: firstKey(), lastKey() 등의 탐색 기능 제공
- Hashtable: 구형 레거시 코드에 주로 사용
