# 13. 컬렉션
```
           Collection
      ┌─────────┴─────────┐
    List                 Set            Map
      ├─ ArrayList        ├─ HashSet     ├─ HashMap
      ├─ Vector           └─ TreeSet     ├─ Hashtable
      └─ LinkedList                      ├─ TreeMap
                                         └─ Properties
```
- List와 Set은 Collection 인터페이스를 상속 받음
- List, Set, Map은 인터페이스

## 13.1. List, Set, Map
|인터페이스|특징|
|---|---|
|List|순서를 유지하고 저장<br>중복 저장 가능|
|Set|순서를 유지하지 않고 저장<br>중복 저장 X|
|Map|키와 값으로 구성된 엔트리 저장<br>키는 중복 저장 X|
