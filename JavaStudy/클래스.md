# 7. 클래스
## 7.1. 클래스란?
- 객체를 만들기 위한 설계도
- 데이터와 기능을 정의하여 같은 형태의 여러 객체를 생성

## 7.2. 구성요소
### 7.2.1. 필드
- 객체가 가지는 데이터와 상태
- 인스턴스 변수, 정적 변수, 상수 등
```java
public class Student{
  //필드
  private String name; //인스턴스 변수
  private int age; //인스턴스 변수
  private static int count; //정적 변수
  public static final String SCHOOL="IT학교"; //상수
  //생성자
  public Student(String name, ing age){
    this.name=name;
    this.age=age;
    count++;
  }
  //메소드
  public void introduce(){
    System.out.println("이름: "+name+", 나이: "+age);
  }
}
```
### 7.2.2. 생성자
- 객체 생성 시 초기화
- 클래스 이름과 동일, 반환형 없음
```java
class Student{
  String name;
  int age;
  //생성자
  Student(String name, int age){
    this.name=name;
    this.age=age;
  }
}
```
#### 7.2.2.1. 기본 생성자
클래스에 생성자 선언이 없으면 컴파일러는 기본 생성자를 바이트코드 파일에 자동으로 추가

**소스 파일(Car.java)**
```java
public class Car{

}
```

#### 7.2.2.2. 생성자 오버로딩
- 매개변수를 달리하는 생성자를 여러 개 선언하는 것
- 매개변수의 타입, 개수, 순서가 다르게 여러 개의 생성자 선언
```java
public class Car{
  Car(){...}
  Car(String model){...}
  Car(String model, String color){...}
  Car(String model, String color, int maxSpeed){...}
}
```

**바이트코드 파일(Car.class)**
```java
public class Car{
  public Car() {} //자동 추가
}
```
### 7.2.3. 메소드
- 객체의 기능과 동작 정의
- 반환형, 매개변수 사용 가능

### 7.2.4. 접근 제어자
- public, protected, default, private
- 접근 범위 제한

### 7.2.5. 정적 멤버(static)
- 클래스에 소속, 객체 없이 사용
- 정적 변수, 정적 메소드

### 7.2.6. 상수(final)
- 값을 변경할 수 없는 변수
- 주로 대문자와 함께 사용

## 7.3. 변수의 종류
|구분|지역 변수|인스턴스 변수|정적 변수|
|---|---|---|---|
|선언 위치|메소드/블록 내부|클래스 내부(메소드 외부)|클래스 내부(변수명 앞에 static)|
|소속|메소드/블록|객체|클래스|
|저장 방식|스택 영역|힙 영역(객체마다 별도)|메소드 영역(클래스당 하나)|
|접근 범위|선언된 블록 내|객체 내|클래스 전체|
|초기화|직접 초기화 필요|기본값 또는 생성자|명시적 초기화|

## 7.4. 초기화 블록
복잡한 초기화에 사용
```java
class Student{
  //인스턴스 필드
  String name;
  int age;
  //정적 필드
	static int count=0;
  //인스턴스 초기화 블록
  { age=20;}
  //정적 초기화 블록
	static { count=1; }
  //생성자
  Student(String name){
    this.name=name;
  }
}
```
### 7.4.1. 인스턴스 초기화 블록
`{}`: 객체가 생성될 때마다 실행

**초기화 순서**
1. 기본값
2. 명시적 초기화
3. 초기화 블록
4. 생성자

### 7.4.2. 스태틱 초기화 블록
`static {}`: 클래스 로딩 될 때 호출되며 각 클래스당 최초 1회만 실행

**초기화 순서**
1. 기본값
2. 명시적 초기화
3. 초기화 블록

## 7.5. this와 super
### 7.5.1. this(현재 객체 참조)
- 현재 객체와 필드/메소드 참조
- 매개변수와 필드 구분할 때 사용
```java
this.name=name;
```
### 7.5.2. super(부모 클래스 참조)
- 부모 클래스의 멤버에 접근
- 부모 생성자 호출
```java
super(name);
```

## 7.6. 객체지향 프로그래밍
### 7.6.1. 객체란?
- 물리적으로 존재하거나 개념적인 것 중에서 다른 것과  식별 가능한 것
- 예: 자동차, 자전거, 책 등

### 7.6.2. 객체지향 프로그래밍의 특징
#### 7.6.2.1. 캡슐화
- 객체의 데이터(필드), 동작(메소드)을 하나로 묶고 실제 구현 내용을 외부에 감추는 것
- 접근 제한자 사용

#### 7.5.2.2. 상속
- 부모 객체가 가지고 있는 필드와 메소드를 자식 객체에게 물려주는 것
- 코드의 재사용성을 높여줌
- 유지 보수 시간을 최소화

#### 7.5.2.3. 다형성
- 사용 방법은 동일하지만 실행 결과가 다양하게 나오는 성질
- 오버로딩, 오버라이딩

## 7.7. 패키지
- 패키지는 클래스의 일부분으로 클래스를 식별하는 용도로 사용
- 개발 회사 도메인 이름의 역순으로 만든다
- 상위 패키지와 하위 패키지를 도트(.)로 구분

### 7.7.1. 선언
- 컴파일러는 클래스의 패키지 선언을 보고 디렉토리를 자동 생성
- 항상 소스 파일 최상단에 위치
- 패키지 이름은 모두 소문자로 작성하는 것이 관례
- 패키지 이름이 중복되지 않도록 회사 도메인 이름의 역순으로 작성 후 마지막에는 프로젝트 이름을 붙여주는 것이 일반적
```java
package 상위패키지.하위패키지;
```

## 7.8. 접근 제한자
- 중요한 필드와 메소드가 외부로 노출되지 않도록 해 객체의 무결성을 유지하기 위해 사용
- default는 생략 가능

|접근 제한자|제한 대상|제한 범위|
|---|---|---|
|public|클래스, 필드, 생성자, 메소드|모든 패키지에서 사용 가능|
|protected|필드, 생성자, 메소드|같은 패키지나 자식 객체만 사용 가능|
|default|클래스, 필드, 생성자, 메소드|같은 패키지|
|private|필드, 생성자, 메소드|객체 내부|
