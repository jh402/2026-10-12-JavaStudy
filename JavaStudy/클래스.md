# 7. 클래스
## 7.1. 클래스란?
- 객체를 만들기 위한 설계도
- 데이터와 기능을 정의하여 같은 형태의 여러 객체를 생성

## 7.2. 구성요소
### 7.2.1. 필드
- 객체가 가지는 데이터와 상태
- 인스턴스 변수, 정적 변수, 상수 등

### 7.2.2. 생성자
- 객체 생성 시 초기화
- 클래스 이름과 동일, 반환형 없음

### 7.2.3. 메소드
- 객체의 기능과 동작 정의
- 반환형, 매개변수 사용 가능

### 7.2.4. 접근 제어자
- public, protected, default, private
- 접근 범위 제한

### 7.2.5. 정적 멤버(static)
- 클래스에 소속, 객체 없이 사용
- 정적 변수, 정적 메소드

### 7.2.6. 상수(final)
- 값을 변경할 수 없는 변수
- 주로 대문자와 함께 사용
