# 7. 클래스
## 7.1. 클래스란?
- 객체를 만들기 위한 설계도
- 데이터와 기능을 정의하여 같은 형태의 여러 객체를 생성

## 7.2. 구성요소
### 7.2.1. 필드
- 객체가 가지는 데이터와 상태
- 인스턴스 변수, 정적 변수, 상수 등
```
public class Student{
  //필드
  private String name; //인스턴스 변수
  private int age; //인스턴스 변수
  private static int count; //정적 변수
  public static final String SCHOOL="IT학교"; //상수
  //생성자
  public Student(String name, ing age){
    this.name=name;
    this.age=age;
    count++;
  }
  //메소드
  public void introduce(){
    System.out.println("이름: "+name+", 나이: "+age);
  }
}
```
### 7.2.2. 생성자
- 객체 생성 시 초기화
- 클래스 이름과 동일, 반환형 없음

### 7.2.3. 메소드
- 객체의 기능과 동작 정의
- 반환형, 매개변수 사용 가능

### 7.2.4. 접근 제어자
- public, protected, default, private
- 접근 범위 제한

### 7.2.5. 정적 멤버(static)
- 클래스에 소속, 객체 없이 사용
- 정적 변수, 정적 메소드

### 7.2.6. 상수(final)
- 값을 변경할 수 없는 변수
- 주로 대문자와 함께 사용

## 7.3. 변수의 종류
|구분|지역 변수|인스턴스 변수|정적 변수|
|---|---|---|---|
|선언 위치|메소드/블록 내부|클래스 내부(메소드 외부)|클래스 내부(변수명 앞에 static)|
|소속|메소드/블록|객체|클래스|
|저장 방식|스택 영역|힙 영역(객체마다 별도)|메소드 영역(클래스당 하나)|
|접근 범위|선언된 블록 내|객체 내|클래스 전체|
|초기화|직접 초기화 필요|기본값 또는 생성자|명시적 초기화|
