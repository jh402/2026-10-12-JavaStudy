<h2>변수</h2>
변수란? 하나의 값을 저장할 수 있는 메모리 공간

데이터 타입 : 모든 변수에는 타입이 있으며 타입에 따라 저장할 수 있는 값의 종류와 범위가 달라짐
|정수 타입|메모리 크기|
|--------|----------|
|byte|1 byte|
|char|2 byte|
|short|2 byte|
|int|4 byte|
|long|8 byte|

|실수 타입|메모리 크기|
|float|4 byte|
|double|8 byte|

|논리 타입|메모리 크기|
|boolean|1 byte|
