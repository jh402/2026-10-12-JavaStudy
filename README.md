## 변수
하나의 값을 저장할 수 있는 메모리 공간
  </summary>
  <details>
    <summary>
      
### 데이터 타입   
모든 변수에는 타입이 있으며 타입에 따라 저장할 수 있는 값의 종류와 범위가 달라짐
    </summary>

|정수 타입|메모리 크기|
|---|---|
|byte|1 byte|
|char|2 byte|
|short|2 byte|
|int|4 byte|
|long|8 byte|

|실수 타입|메모리 크기|
|---|---|
|float|4 byte|
|double|8 byte|

|논리 타입|메모리 크기|
|---|---|
|boolean|1 byte|
  
  </details>

### 변수 선언
타입 변수이름; 형식으로 선언<br>
예시) int age;

### 타입 변환
데이터 타입을 다른 타입으로 변환하는 것<br>
크기 순서 : byte &#60; short &#60; int &#60; long &#60; float &#60; double<br>
자동(묵시적) 타입 변환 : 작은 크기의 타입이 큰 크기의 타입에 자장될 때 발생<br>
강제(명시적) 타입 변환 : 큰 타입을 작은 타입을 쪼개어 저장하는 것
</details>

## 연산자
연산자는 데이터를 계산하고, 비교하고, 조건을 판단하는 도구
  </summary>
  <details>
    <summary>
      
### 산술연산자
숫자를 계산할 때 사용
    </summary>

|연산자|의미|예시|
|-----|---|----|
|+|덧셈|10+3 -\> 13|
|-|뺄셈|10-3 -\> 7|
|*|곱셈|10*3 -\> 30|
|/|나눗셈|10/3 -\> 3|
|%|나머지|10%3 -\> 1|

**주의**<br>
정수/정수=정수<br>
정수/실수=실수<br>

**%연산자는 앞의 부호를 따라감**<br>
10%3 -\> 1<br>
10%-3 -\> 1<br>
-10%3 -\> -1<br>
-10%-3 -\> -1<br>
  </details>

  <details>
    <summary>
      
### 증감연산자
변수의 값을 1증가 또는 감소 시킬 때 사용
    </summary>

|연산자|의미|예시|
|------|----|----|
|++|1 증가|a++<br>++a|
|--|1 감소|a--<br>--a|

|형식|설명|예시(결과)|
|----|---|-----------|
|a++|사용 후 증가|int a=5;<br>int b=a++; (b=5, a=6)|
|++a|증가 후 사용|int a=5;<br>int b=++a; (b=6, a=6)|
  </details>

### 부정 연산자
boolean의 값을 반대로 바꿀 때 사용
    </summary>
    
|연산자|의미|예시(결과)|
|------|----|----------|
|!|논리 부정|!true -> false|
  </details>

    <summary>
      
### 형변환 연산자
데이터형을 다른 데이터형으로 바꿀 때 사용
    </summary>
    
|구분|연산자|설명|예시(결과)|
|----|-----|----|---------|
|자동형변환||작은 타입의 값의 허용범위가 큰 타입으로 대입될 때 발생|double b=10; (10.0)|
|강제형변환|(데이터타입)|큰 타입을 작은 허용 범위 타입으로 쪼개어서 저장|int b=(int)3.14; (3)|
  </details>
  <details>
    <summary>
      
### 비교 연산자
두 값을 비교하여 true / false를 반환
    </summary>
    
|연산자|의미|예시(결과)|
|-----|----|----------|
|==|같다|10==10 -> true|
|!=|다르다|10!=10 -> false|
|>|크다|10>5 -> true|
|<|작다|10<5 -> false|
|>=|크거나 같다|10>=5 -> true|
|<=|작거나 같다|10<=5 -> false|

**주의**
문자열 비교는 ==연산자 대신 equals() 사용
  </details>

  <details>
    <summary>
      
### 논리 연산자
여러 조건을 조합할 때 사용
    </summary>

|연산자|의미|예시(결과)|
|-----|----|-----------|
|&&|AND|true && false -> false<br>true && true -> true|
|\|\||OR|true \|\| false -> true<br>false \|\| false -> false|
|!|NOT|!true -> false|

**단락 평가**
&&연산자 앞이 false면 뒤를 검사하지 않음<br>
||연산자 앞이 true면 뒤를 검사하지 않음

예시<br>
int a=10, b=20;<br>
System.out.println(a>b && ++b==21);//false<br>
System.out.println(b);//20<br>

  </details>

### 대입 연산자
변수에 값을 저장하거나 갱신할 때 사용
    </summary>
    
|연산자|의미|사용처|예시|
|-----|----|-----|-----|
|=|대입|초기값 저장|a=10|
|+=|더한 후 대입|누적 계산, 문자열 결합|a+=5|
|-=|뺀 후 대입|감소 처리|a-=5|
|*=|곱한 후 대입|배율 계산|a*=5|
|/=|나눈 후 대입|평균, 분배|a/=5|
|%=|나머지 대입|짝수/홀수|a%=2|

  </details>

    <summary>
      
### 비트 연산자
정수의 2진수 비트를 기준으로 연산
    </summary>
    
|연산자|의미|주로 사용하는 곳|예시(결과)|
|------|---|-----|------------|
|&|AND|특정 비트 확인|5&3 -> 1|
|\||OR|비트 설정|5\|3 -> 7 |
|^|XOR|비트 반전/제어|5^3 -> 6|
|~|NOT|모든 비트 반전|~5 -> -6|

  </details>

### 비트 이동 연산자
비트를 왼쪽 또는 오른쪽으로 이동
    </summary>

|연산자|의미|주로 사용하는 곳|예시(결과)|
|-----|----|---------------|------------|
|\<\<|왼쪽 이동|비트 플래그, 곱셈|8\<\<1 -> 16|
|\>\>|오른쪽 이동<br>(부호 유지)|정수 처리|8\>\>1 -> 4|
|\>\>\>|오른쪽 이동<br>(0으로 채움)|부호 없는 해석|8>>>1 -> 4|
  </details>

### 삼항 연산자
